# Deep Structure Mastering Studio

Installierbare Web-App (PWA) unter `deepstructure.world/studio/`.
Audio-Editor und Mastering-Kette: EQ, 3-Band-Kompressor, Sättigung, Stereo/Bass-Mono,
True-Peak-Limiter, LUFS-Messung (ITU-R BS.1770), Referenz-Vergleich, WAV-Export.

- Läuft komplett im Browser, Audiodateien verlassen das Gerät nie.
- `sw.js` cacht die App für Offline-Start. Bei jedem Update `VERSION` in `sw.js` erhöhen.
- Keine Build-Schritte, keine Abhängigkeiten außer Google Fonts.
